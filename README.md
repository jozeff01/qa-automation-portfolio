# QA Automation Portfolio Project

Comprehensive automated testing framework built with Playwright, TypeScript, and GitHub Actions, covering UI, API, and QA documentation standards.

## Tech Stack & Tools

- **Language:** TypeScript, JavaScript
- **Test Framework:** Playwright (UI & API automation)
- **Architecture:** Page Object Model (POM)
- **CI/CD:** GitHub Actions
- **Version Control:** Git & GitHub

---

## Project Structure

```text
├── .github/workflows/   # CI/CD pipelines (GitHub Actions)
├── docs/                # Professional QA documentation
│   ├── test-cases.md    # Functional test cases
│   └── bug-reports.md   # Bug tracking examples
├── tests/               # Automated test suites
│   ├── api/             # API automation (RESTful-booker integration)
│   └── login.spec.ts    # UI tests using Page Object Model (POM)
├── pages/               # Page Object classes (UI locators & methods)
└── package.json         # Project dependencies & scripts
```
